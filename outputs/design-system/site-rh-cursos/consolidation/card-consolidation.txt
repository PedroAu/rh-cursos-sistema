CONSOLIDATION STRATEGY
----------------------

Enhance src/components/ui/card.tsx with CVA variant system:

export const Card = cva(
  "rounded-md bg-card border border-border overflow-hidden",
  {
    variants: {
      variant: {
        base: "shadow-sm",
        elevated: "shadow-md hover:shadow-lg",
        outlined: "border-2",
        filled: "bg-surface border-none",
      },
      interactive: {
        true: "cursor-pointer transition-shadow hover:shadow-lg",
        false: "",
      },
      size: {
        sm: "p-4",
        md: "p-6",
        lg: "p-8",
      }
    },
    defaultVariants: {
      variant: "base",
      interactive: false,
      size: "md"
    }
  }
);

DOMAIN-SPECIFIC WRAPPERS
------------------------

Instead of separate components, create lightweight wrappers:

// src/components/agenda/class-card.tsx (refactored)
export const ClassCard = ({ class: ClassEvent, interactive = true }) => (
  <Card variant="elevated" interactive={interactive} size="sm">
    {/* class-specific content */}
  </Card>
);

// src/components/courses/course-card.tsx (refactored)
export const CourseCard = ({ course, compact = false }) => (
  <Card 
    variant={compact ? "outlined" : "elevated"} 
    interactive={true}
    size={compact ? "sm" : "md"}
  >
    {/* course-specific content */}
  </Card>
);

// Similar refactors for: BlogCard, TestimonialCard, ChartCard
