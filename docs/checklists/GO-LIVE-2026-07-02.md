## Roteamento de modelos (gestão de tokens)

| Trabalho | Modelo | Racional |
|----------|--------|----------|
| Commits, checklist, monitoramento | Haiku | Mecânico, zero raciocínio profundo |
| Testes, fixes pontuais, deploy ops | Sonnet | Padrão custo/benefício |
| Security review, debug de falha de deploy | Opus | Único ponto onde erro custa o go-live |
| Orquestração | Sessão principal | Não re-executa evidência já coletada |

**Regras de economia:** builds/testes em background; nunca repetir verificação já verde na mesma fase; escalar Opus apenas sob falha; um único full-run (`npm run test`) antes do deploy, não vários parciais redundantes.
