# Legacy Token Snapshots

Este diretório guarda snapshots antigos de tokens que antes ficavam em `docs/design/`.

Motivo do arquivamento:

- a fonte ativa de tokens está em `src/design-tokens/`
- estes arquivos representam extrações e experimentos anteriores
- manter no diretório principal de design gerava falsa concorrência com a implementação real

Use este material apenas para auditoria ou comparação histórica.
