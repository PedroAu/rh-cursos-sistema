## Contexto

A EP-0.3 fecha a base visual da Fundacao Executive Precision sem recriar componentes. A spec FR-4 exige botoes primario gold/navy, secundario ghost navy e terciario text-button; card com top-accent navy e elevacao Level 1; chips pill com tint de baixa saturacao; inputs outlined com label `label-bold` acima e foco azul com glow. O trabalho deve preservar APIs existentes e deixar a ativacao por rota para as fases seguintes.

## Acceptance Criteria

- [x] AC1 — `Button` preserva as variantes existentes e expõe o reskin Executive Precision por tokens: primaria gold/navy, secundaria ghost navy quando em `[data-theme="executive"]`, e variante terciaria text-button (FR-4, CON-1).
- [x] AC2 — `Card` preserva a API existente e suporta top-accent navy sem recriar componente; elevacao Level 1 usa borda 1px e sombra `0 4px 12px rgba(0,0,0,0.05)` (FR-4, CON-1).
- [x] AC3 — `Badge`/chips usam formato pill, tint de baixa saturacao e contraste AA nos estados existentes (FR-4, NFR-1).
- [x] AC4 — Inputs, textarea, select e `FormField` usam outlined + label `label-bold` acima + foco tokenizado com glow azul no tema executive (FR-4, NFR-1).
- [x] AC5 — Footer publico passa a consumir token navy do tema executive sem alterar contrato do shell; newsletter permanece fora de escopo para EP-1.1 (FR-4, CON-1).
