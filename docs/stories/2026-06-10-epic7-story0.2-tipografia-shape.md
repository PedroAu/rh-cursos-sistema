## Contexto

A EP-0.1 adicionou a paleta Executive Precision e o escopo `[data-theme="executive"]` sem ativar rotas. A EP-0.2 continua a Fundacao: remove o carregamento de fontes por CDN, disponibiliza Montserrat + Inter via `next/font/google`, expõe a escala tipografica, radius, grid e spacing do DESIGN.md como tokens, e prepara o re-apontamento sem recriar componentes.

Decisao arquitetural do epico (§2 Fontes): substituir `@import` CDN (Inter+Manrope) por `next/font/google` (Montserrat + Inter) self-hosted, critico para Cloudflare Workers/OpenNext. A spec FR-2 exige Montserrat para headings, Inter para body/UI, escala do DESIGN.md como tokens e remocao do `@import` CDN. A spec FR-3 exige radius 4px para botoes/inputs, 8px para cards, pill para chips, grid 8px, container 1200px e gutter 24px. Para preservar as rotas ainda nao migradas, Manrope permanece apenas como fonte legada self-hosted via `next/font` no tema atual; o scope `[data-theme="executive"]` aponta headings para Montserrat.
