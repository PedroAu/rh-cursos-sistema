## Story

**As a** visitor or admin user,  
**I want** priority pages to use consistent design-system layout primitives,  
**so that** RH Cursos has predictable spacing, typography, and responsive behavior across key surfaces.

## Acceptance Criteria

1. The story identifies a bounded first migration set from `docs/design-system-audit.md` and `docs/design-system.md`.
2. `Container` and `Section` primitives are implemented or reused according to the documented design-system direction.
3. The selected marketing/shared pages remove duplicated ad hoc container/section patterns where replaced.
4. Visual layout remains responsive on mobile and desktop.
5. Tests or visual/manual verification notes cover the migrated surfaces.
6. The story file Dev Agent Record lists every migrated page/component.
