## Story

**As a** maintainer,  
**I want** dependency vulnerabilities triaged and patched or explicitly waived,  
**so that** releases have a known dependency risk posture.

## Acceptance Criteria

1. `npm audit --audit-level=moderate` is re-run and result is captured.
2. If a patched compatible Next version exists, dependencies are upgraded and tests/build pass.
3. If no compatible patched version exists, a documented waiver is created with rationale, impact, monitoring trigger, and expiration date.
4. `package-lock.json` is updated only when a real dependency change is made.
