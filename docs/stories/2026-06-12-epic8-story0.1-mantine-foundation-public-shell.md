## Epica
EP-8 — Migração de UI para Mantine por direção do usuário em 2026-06-12

## Contexto

O projeto atual foi redesenhado sobre uma base própria de Tailwind/Radix. A nova direção do produto exige reconstruir a camada de UI com a biblioteca oficial `mantinedev/mantine`, usando provider, tema, hooks, forms e componentes nativos como fundação do design system. Esta primeira onda cobre a infraestrutura global da biblioteca, o shell público e a tela de login para remover o menu antigo e estabelecer o stack novo sem herdar a camada visual anterior nesses pontos.
