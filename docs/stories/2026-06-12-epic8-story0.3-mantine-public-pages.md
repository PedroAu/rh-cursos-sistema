## Status

Done

## Epica

EP-8 — Migração de UI para Mantine por direção do usuário em 2026-06-12

## Contexto

Com o shell público (0.1) e o shell administrativo (0.2) já migrados para Mantine, esta onda reconstrói as seis páginas públicas internas — Home, Cursos, Agenda, Contato, In-Company e Sobre — que ainda dependem da camada de classes CSS próprias (`rh-*`/`ea-*`) herdada do redesign anterior. A lógica de dados (store, formulários, filtros) é preservada; a superfície visual passa a usar primitives Mantine (`Container`, `Stack`, `Group`, `SimpleGrid`, `Grid`, `Card`, `Paper`, `Title`, `Text`, `Button`, `Accordion`, `TextInput`, `Select`, etc.) com os tokens do tema (`rhBlue`, `rhGold`, radius, shadows).

### Completion Notes

- As seis páginas públicas internas foram reconstruídas sobre primitives Mantine, abandonando as classes próprias `rh-*`/`ea-*` e os componentes de UI antigos (`@/components/ui/{button,select,input,textarea,form-field,accordion}`).
- Formulários de Contato e In-Company migraram para `TextInput`/`Textarea`/`Select`/`Checkbox` Mantine (com `error` nativo), preservando estado, máscaras de telefone e validação manual; `Alert` substitui os banners de sucesso/erro.
- Filtros de Catálogo e Agenda usam `Select` e `Button` Mantine; componentes comuns (`CourseCard`, `SearchInput`, `CalendarView`, `EmptyState`, `LoadingBlocks`) foram mantidos como estão.
- Acessibilidade: corrigidas todas as violações WCAG AA de contraste introduzidas pela paleta nova (axe verde em `/`, `/cursos`, `/agenda`, `/contato`, `/falar-com-especialista`, `/login`).
- Gate de reduced-motion (epic5): removido `tt="uppercase"` inline da Home (o seletor `[style*="transform"]` casava com `text-transform`) e `transitionDuration={0}` no Accordion para zerar `opacity:0` inline nos painéis fechados.
- Verificação final: `npm run lint` (ok), `npm run typecheck` (ok), `npm test` (build + Playwright, 102 passed). 4 snapshots de governança rebaselined.
