## Story

**As a** site visitor and admin user,  
**I want** the browser to receive baseline security headers,  
**so that** XSS impact, clickjacking, MIME sniffing, referrer leakage, and excessive browser permissions are reduced.

## Acceptance Criteria

1. `next.config.ts` defines global security headers through `headers()`.
2. Baseline includes `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, and either `X-Frame-Options` or CSP `frame-ancestors`.
3. CSP is added enforced or report-only with documented allowlist.
4. HSTS is included only when safe for HTTPS production deployment.
5. Verification confirms headers on representative public, login, and admin routes.
