**I want** `src/lib/admin-data.ts` decomposed or bounded by clear module seams,

2. A decomposition plan is documented and scoped to a first safe slice.
3. The first slice moves or extracts code without changing admin behavior.
4. Existing imports are updated consistently.
5. Tests cover the moved/extracted behavior or existing coverage is preserved.
6. The story records any remaining large-module debt as follow-up work.
