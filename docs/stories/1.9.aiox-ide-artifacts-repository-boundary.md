## Story

**As a** repository maintainer,  
**I want** AIOX and IDE agent artifacts intentionally tracked or ignored,  
**so that** app source concerns and local tooling artifacts do not create noisy or risky repository state.

## Acceptance Criteria

1. Current AIOX/IDE artifact directories in the worktree are inventoried.
2. Each directory is classified as required project artifact, local-only artifact, or generated/cache artifact.
3. `.gitignore` or repository documentation is updated to reflect the intended boundary.
4. Required AIOX artifacts needed by the team remain available and are not accidentally hidden.
5. The decision is documented for future contributors.
6. No application source behavior changes in this story.
