## Story

**As a** maintainer preparing production changes,  
**I want** Playwright E2E coverage for critical user and admin flows,  
**so that** regressions in login, enrollment, and checkout are caught before deployment.

## Acceptance Criteria

1. An E2E test location exists and is wired into the existing Playwright configuration.
2. At least one login/admin access flow is covered.
3. At least one public lead or enrollment flow is covered.
4. Pix/Boleto checkout behavior is covered at a safe level using mocks or test-mode assumptions; no real charge is required.
5. Tests are documented with required environment/test data setup.
6. `npm run test:e2e` runs the new specs locally or documents any required external dependency that blocks execution.
